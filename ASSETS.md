# Alfred assets

This is the descriptive visual layer for proposed v0.2. It does not define runtime behaviour.

| Asset | Dimensions | Use |
|---|---:|---|
| `alfred-full-body.png` | 1024 × 1536 RGBA | Introductions and briefing covers; use a pale container on busy or dark backgrounds. |
| `alfred-avatar.png` | 1254 × 1254 RGB | Opaque pale-square avatar. Prefer 48 CSS px, 32 for identity only, 96 for profile context. |
| `alfred-concept-reference.png` | 1536 × 1024 RGB | Stable identity reference for future visual work. |
| `alfred-mood-board.png` | 1536 × 1024 RGB | Expression and material reference, not isolated pose assets. |

Preserve proportions, do not mirror or stretch, and keep one eye-width of clear space around the head. The temple mark is character-left, viewer-right in front view. Keep the charcoal collarless jacket, cream collar edge, red chest tab, footwear, matte ivory ceramic, and soft studio light. Use “Alfred” as alt text when naming the sender; use empty alt text when adjacent text already names him.

The four visual cues map to interaction intent: attentive notices and receives without forcing questions; considering accompanies real evidence work; your decision marks an actual choice; acknowledged confirms an exact evidenced action. They are not a mandatory state machine or fake runtime status.

For future generation, attach `alfred-concept-reference.png` and specify: preserve the supplied Alfred identity, proportions, matte ivory ceramic head, charcoal textile clothing, cream collar, red chest tab, and red temple inset; change only the requested pose or expression; use soft studio light; add no accessories, text, or branding; request genuine transparent alpha for a cutout and inspect it on light and dark backgrounds.

Original inspiration: [Moein’s mascot reference](https://x.com/designbymoein/status/2096289484577071567).
